## What you will be able to demonstrate

- Configure and publish a GitHub Pages site through reviewed source changes and GitHub Actions.
- Correctly configure project-site base paths and avoid broken stylesheets or JavaScript.
- Design and validate CNAME or apex-domain records, with change-control and rollback evidence.
- Verify HTTPS and recognize dangling-domain and deployment credential risks.
- Troubleshoot failing builds, certificates, custom domains and route resolution.
- Deliver a multi-page capstone website with reproducible test evidence and an operations runbook.

## What you need

A GitHub account, Git or Codespaces access, a text editor, Node.js 20 or later for the Docusaurus lab, and PowerShell or Bash. DNS zone permissions are optional: when unavailable, complete a clearly labeled simulation instead of modifying production records.

**Assessment and evidence:** The formative quiz and six-criterion capstone rubric appear in Module 7. The activities across the modules generate an Evidence of Capability Record that an assessor can review.
