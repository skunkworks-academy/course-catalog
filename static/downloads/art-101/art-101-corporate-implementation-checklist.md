# ART-101 Corporate Cohort Implementation Checklist

## Governance

- [ ] Executive sponsor confirmed.
- [ ] Programme owner confirmed.
- [ ] Learner population and business outcomes defined.
- [ ] Assessment and moderation roles assigned.
- [ ] Evidence retention and privacy rules approved.
- [ ] Escalation and appeal process documented.

## Technical readiness

- [ ] Learner Portal accounts tested.
- [ ] ART-101 enrolment records created or activated.
- [ ] Microphone and camera access tested on supported browsers.
- [ ] Approved evidence repository provisioned.
- [ ] Sharing permissions use least privilege.
- [ ] Recording consent process configured.
- [ ] Accessibility and captioning requirements confirmed.

## Learning delivery

- [ ] Baseline diagnostic scheduled.
- [ ] Practice and submission calendar published.
- [ ] Peer practice groups assigned.
- [ ] Manager or mentor feedback checkpoints scheduled.
- [ ] Capstone topics approved.
- [ ] Reviewer scorecard distributed.
- [ ] Support channels and response targets communicated.

## Assessment quality

- [ ] Assessors calibrated against the rubric.
- [ ] Example competent and not-yet-competent evidence reviewed.
- [ ] Verification interview process tested.
- [ ] Moderation sample defined.
- [ ] Resubmission period defined.
- [ ] Certificate and badge approval workflow confirmed.

## Transfer of learning

- [ ] Each learner has an approved workplace application task.
- [ ] 30-day manager review scheduled.
- [ ] 60-day application checkpoint scheduled.
- [ ] 90-day capability validation scheduled.
- [ ] Business outcome and behaviour measures defined.
- [ ] Programme evaluation owner assigned.

## Close-out

- [ ] Completion and non-completion records reconciled.
- [ ] Evidence links tested and retained according to policy.
- [ ] Assessment decisions moderated.
- [ ] Certificates and badges issued only to competent learners.
- [ ] Learner and manager feedback analysed.
- [ ] Improvement actions logged for the next cohort.
